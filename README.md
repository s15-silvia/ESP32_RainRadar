# RainRadar

## 概要

ESP32と2.8インチTFT液晶を使用して、気象庁の高解像度降水ナウキャスト（雨雲レーダー）を表示するプログラムです。

背景地図と雨雲レーダーの画像を合成し、320×187ピクセルの表示領域に描画します。

## ハードウェア

- マイコン：ESP32-DevKitC-32E
- ディスプレイ：2.8インチ ILI9341 TFT液晶
- ディスプレイ接続：SPI

## 開発環境

- Arduino IDE：2.3.10
- ESP32 Arduino Core（esp32 by Espressif Systems）：3.3.12
- LovyanGFX：1.2.33
- ArduinoJson：7.4.3
- pngle：1.1.0

上記は開発・動作確認に使用した環境です。

## セットアップ

1. Arduino IDEをインストールします。
2. ESP32用のボードパッケージをインストールします。
3. 必要なライブラリをインストールします。
4. `RainRadar.ino` をArduino IDEで開きます。
5. ソースコード内の設定を確認し、必要に応じて変更します。
6. 使用するESP32ボードを選択し、プログラムを書き込みます。

> **注意：** Arduino IDE、ボードパッケージ、ライブラリのバージョンによっては、コンパイル結果や動作が異なる場合があります。

## 使用上の注意

- 雨雲レーダー画像や背景地図の取得には、インターネット接続が必要です。
- Wi-Fi接続に必要な設定を確認してください。
- ディスプレイの接続方法や設定は、使用するハードウェアに合わせて確認してください。
- 通信状況やデータの配信状況によっては、画像を取得できない場合があります。
- 気象情報の確認には、気象庁などの公式情報も併せて利用してください。
